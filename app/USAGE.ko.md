# L99 Stream Deck 편집기

11개 버튼을 넘패드 `0~9`, `/` 순서로 편집합니다. 각 행의 위쪽은 사용자 지정 이름, 아래쪽은 파일 경로 또는 HTTP/HTTPS 주소입니다. 이름 오른쪽의 **아이콘 설정**으로 이미지 파일을 고르고, **기본 아이콘**으로 파일의 Windows 기본 아이콘을 다시 사용할 수 있습니다. 웹 주소는 기본 브라우저로 열립니다. 웹사이트 아이콘은 네트워크 조회 없이 공통 웹 아이콘을 사용합니다.

**설정 저장**은 실행 대상에 바로 반영됩니다. 실행 시 연결이 자동으로 켜지고, 키보드 홈에서 스트림덱에 진입하면 11개 버튼이 활성화됩니다. 뒤로가기로 해제합니다. NumLock을 켜 주세요. **연결 끄기** 또는 **완전 종료**로 연결과 단축키 예약을 해제합니다. 연결 중 넘패드 `-`/`+`는 진입·종료 신호로 예약됩니다.

데스크톱 개정: 앱을 실행하면 연결이 자동으로 켜집니다. 최소화 버튼은 트레이로 보내며 연결이 유지됩니다. X는 **트레이로 이동 / 완전 종료 / 취소** 선택 창을 엽니다. 트레이 메뉴에서도 열기·완전 종료가 가능합니다. 같은 프로그램을 다시 실행하면 기존 창을 엽니다. **Windows 시작 시 자동 실행** 체크박스는 현재 사용자 계정에 등록하며, 로그인 시 트레이에서 실행됩니다. 체크를 해제하면 등록을 제거합니다.

아이콘 적용 성공 후 연결을 자동으로 켭니다. 전체 펌웨어 적용 중에는 연결을 끄고, 기본 업데이터 창이 닫히면 연결을 다시 켭니다. 100%·OK 확인과 키보드 재시작은 필요합니다. 적용 중에는 완전 종료를 막지만 트레이 이동은 가능합니다. 트레이 이동은 종료가 아니며 **완전 종료**할 때 단축키 예약이 해제됩니다.

**펌웨어 적용**은 이름·아이콘을 포함한 화면 리소스를 생성하고 제조사 기본 업데이터 1.31을 엽니다. 고속 수정본을 사용하지 않습니다. USB 모드에서 Fn+스페이스로 화면을 끈 뒤 업데이터의 Start를 직접 누릅니다. 약 10분 걸리며 100%·OK까지 전원을 유지해야 합니다. 실행 경로만 변경할 때는 다시 적용할 필요가 없습니다.

**아이콘 적용**은 이름·아이콘이 들어 있는 전용 영역 384KB만 전송합니다. 기본 업데이터를 닫고, USB 모드에서 Fn+스페이스로 화면을 끈 뒤 확인을 누릅니다. 적용 전후 전체 CRC 검증을 포함해 약 2~3분 걸립니다. 완료 안내 뒤 키보드를 껐다 켜세요. 연결 프로그램은 적용 시 꺼지며 필요하면 다시 켭니다.

아이콘 전용 레이아웃이 먼저 설치되어 있어야 합니다. 확인된 기준과 다른 화면이면 기록하지 않고 중단합니다. 사진 액자·배경·기존 기능을 위한 영역은 부분 전송 대상에 포함하지 않습니다. 다른 도구로 화면이나 사진을 변경하면 기준 CRC가 달라져 아이콘 적용이 중단될 수 있습니다. 이 경우 새 기준을 확인하기 전에는 전체 적용으로 사용자 사진을 덮어쓰지 마세요. 전송 도중 실패하면 자동 재시도하지 않으며 기본 업데이터 복구가 필요할 수 있습니다.

글꼴·배치 개정 3: 홈의 스트림덱 아이콘을 주변과 같은 50×50 크기로 맞췄습니다. 스트림덱 이름과 내부의 한글·영문 이름, 뒤로가기는 [갈무리11](https://github.com/quiple/galmuri) BDF 원본 픽셀로 표시합니다. 긴 이름은 좁은 폭 버전을 사용하며 그래도 넘치면 말줄임합니다. 시스템에 글꼴을 설치하지 않습니다. 글꼴은 SIL Open Font License 1.1이며 원문은 `assets/fonts/LICENSE.txt`에 있습니다. 다른 메뉴의 글꼴은 바꾸지 않습니다. 이 개정으로 전환할 때 한 번 전체 적용이 필요하며, 이후에는 아이콘 적용을 사용할 수 있습니다.

설정과 사용자 아이콘은 이 프로그램 폴더의 `data`에만 저장됩니다. 경로·주소에는 개인정보가 포함될 수 있으므로 이 폴더는 배포하거나 GitHub에 올리지 마세요. 로그인 자동 실행, 인터넷 아이콘 다운로드, 통계 수집은 하지 않습니다.

원본 Python 실행: `python main.py` (Windows, Python 3, Pillow, pyserial 필요).
