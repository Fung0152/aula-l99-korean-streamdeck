# AULA L99 한글화·스트림덱 사용 방법

## 1. 다운로드와 준비

1. [Releases](https://github.com/Fung0152/aula-l99-korean-streamdeck/releases/latest)에서 **L99StreamDeck-Windows-v0.1.0.zip**을 받습니다. 시험판이 latest 목록에 나타나지 않으면 [v0.1.0 페이지](https://github.com/Fung0152/aula-l99-korean-streamdeck/releases/tag/v0.1.0)를 이용하세요.
2. ZIP을 우클릭해 **모두 압축 풀기**를 실행합니다. ZIP 안에서 EXE만 바로 실행하거나 EXE만 다른 폴더로 옮기지 마세요. `_internal`, `assets`, `vendor`가 함께 있어야 합니다.
3. 압축을 푼 폴더를 계속 사용할 위치에 둡니다. 자동 시작을 등록한 뒤 폴더를 옮겼다면 새 위치에서 등록을 다시 설정해야 합니다.
4. 키보드를 PC에 USB로 연결하고 **유선 USB 모드**를 선택합니다. 개발 기기에서는 Fn+4가 USB 모드입니다. **NumLock도 켜 주세요.**
5. 예전 L99 연결 프로그램이 켜져 있다면 완전 종료합니다. `L99StreamDeck.exe`를 실행하면 연결이 자동으로 켜집니다.

처음 설치하는 경우에는 아래 **최초 전체 적용**을 한 번 진행합니다. 이미 이 배포본과 호환되는 통합 화면이 설치돼 있다면 **평소 사용**부터 진행하면 됩니다.

## 2. 바로가기 편집

화면의 각 행은 스트림덱 안의 버튼 하나에 대응합니다.

| 디스플레이 위치 | 왼쪽부터 오른쪽 순서 |
|---|---|
| 첫 번째 줄 | NUM 0 · NUM 1 · NUM 2 · NUM 3 |
| 두 번째 줄 | NUM 4 · NUM 5 · NUM 6 · NUM 7 |
| 세 번째 줄 | NUM 8 · NUM 9 · NUM / · 뒤로가기 |

- **이름:** 키보드 화면에 보일 이름입니다. 가독성을 위해 짧게 지정하세요. 긴 이름은 좁은 폭 글꼴이나 말줄임으로 표시될 수 있습니다.
- **파일 경로:** 실행할 프로그램·파일·폴더·바로가기를 고릅니다. 아래 경로 칸을 직접 수정해도 됩니다. Windows 메모장 예시는 `C:\Windows\System32\notepad.exe`입니다.
- **웹사이트:** 같은 경로 칸에 `https://www.youtube.com/` 또는 `https://chatgpt.com/`처럼 주소를 입력하면 기본 브라우저로 엽니다.
- **아이콘 설정:** 별도의 이미지 파일을 지정합니다. **기본 아이콘**은 지정한 이미지 대신 파일의 Windows 아이콘을 다시 사용합니다. 웹 주소에는 공통 웹 아이콘이 사용됩니다.
- 편집이 끝나면 **설정 저장**을 누릅니다. 경로를 삭제하면 해당 버튼은 실행 대상을 갖지 않습니다. 초기 GPT 예시는 설치된 앱 경로에 따라 동작하지 않을 수 있으므로 본인 PC의 프로그램이나 웹 주소를 지정하세요.

## 3. 최초 전체 적용: 한글화·스트림덱·글꼴 설치

**전체 적용은 기기에 저장된 사진·GIF·배경을 배포 기준 데이터로 덮어쓸 수 있습니다. 보존해야 할 콘텐츠가 있다면 바로 진행하지 마세요. 배포 화면 파일은 기기에서 읽은 백업이 아닙니다.**

1. 이름·경로·아이콘을 편집하고 **설정 저장**을 누릅니다.
2. **펌웨어 적용**을 누르고 파일 생성 안내를 확인합니다.
3. 기본 업데이터가 열리면 키보드가 **USB 모드**인지 확인합니다.
4. **Fn+스페이스를 약 5초** 눌러 키보드 디스플레이를 끕니다. Windows에 장치가 다시 연결될 때까지 잠시 기다립니다.
5. 업데이터의 **Start**를 한 번 누릅니다. 편집기의 버튼을 누르는 것만으로 기록이 시작되지는 않습니다.
6. **100%·OK**가 나올 때까지 기다립니다. 개발 기기에서 약 **10분** 걸렸습니다. 창을 강제 종료하거나 USB를 빼거나 전원을 끄지 마세요.
7. **100%·OK를 확인한 뒤** 업데이터를 닫고 키보드를 껐다 켭니다. 필요하면 USB 모드를 다시 선택합니다.
8. 업데이터 창이 닫히면 PC 편집기가 연결을 다시 켭니다. 홈의 **스트림덱**을 눌러 들어갑니다.

영어 메뉴가 그대로 보인다면 설정의 언어 선택을 확인하세요. 이 프로젝트는 기존 중국어 언어 영역을 한국어로 바꾸며, 영어 영역은 유지합니다.

`L99-integrated-screen-v0.1.0.zip`은 기본 통합 화면과 원본 업데이터가 든 별도 패키지입니다. 기본 화면을 직접 설치하거나 전체 복구가 필요할 때 사용합니다. **일반적인 최초 설치는 Windows 편집기의 펌웨어 적용으로 충분하며 두 ZIP을 순서대로 모두 기록할 필요는 없습니다.**

## 4. 평소 사용하는 순서

1. `L99StreamDeck.exe`를 실행합니다. Windows 자동 시작을 켜뒀다면 로그인 후 트레이에서 실행됩니다.
2. 프로그램에 **연결 켜짐**이 표시되는지 확인합니다. 꺼져 있다면 **연결 켜기**를 누릅니다.
3. 키보드 홈에서 **스트림덱**을 누릅니다. 이미 스트림덱 화면이 열린 상태에서 PC 연결을 다시 켰다면 **뒤로가기 → 스트림덱 진입**을 한 번 해 주세요.
4. 실행할 아이콘을 터치합니다. 프로그램 또는 웹사이트가 PC에서 열립니다.
5. 오른쪽 아래 **뒤로가기**로 홈에 돌아갑니다.

PC 연결 프로그램이 켜져 있어야 바로가기 실행이 작동합니다. 창은 최소화해 트레이에 둘 수 있습니다. 디스플레이 진입은 넘패드 `-`, 종료는 넘패드 `+` 신호를 사용하므로 연결 중 두 키는 예약됩니다. 스트림덱 모드에서는 물리 넘패드 `0~9`, `/`도 바로가기로 처리됩니다. 뒤로가기 후 숫자·나누기는 일반 입력으로 돌아가며, **완전 종료**하면 모든 예약을 해제합니다.

## 5. 변경한 내용에 맞는 버튼 선택

| 바꾼 내용 | 누를 버튼 | 화면 끄기 | 예상 시간 |
|---|---|---|---|
| 프로그램 경로·파일·웹 주소만 변경 | 설정 저장 | 필요 없음 | 바로 반영 |
| 키보드에 보이는 이름·아이콘 변경 | 아이콘 적용 | 필요 | 약 2~3분 |
| 최초 설치·화면 구성 변경·전체 복구 | 펌웨어 적용 | 필요 | 약 10분 |

### 이름·아이콘만 적용하기

1. 원하는 이름·아이콘을 편집하고 **설정 저장**을 누릅니다.
2. 기본 업데이터가 열려 있다면 닫습니다.
3. USB 모드에서 **Fn+스페이스를 약 5초** 눌러 화면을 끄고 잠시 기다립니다.
4. 편집기에서 **아이콘 적용**을 누르고 준비 안내의 **확인**을 누릅니다.
5. 생성·기존 화면 검사·아이콘 전송·전체 보존 검증이 끝날 때까지 USB와 전원을 유지합니다. 전송량은 384KB지만 전체 CRC 검증 때문에 약 2~3분 걸립니다.
6. **아이콘 적용 완료**가 표시된 뒤 키보드를 껐다 켭니다. 연결은 자동으로 다시 켜집니다.

기준 화면이 다르다는 오류가 나면 이미지 기록 전에 중단합니다. 다른 한글화 버전이나 다른 도구로 바꾼 사진·화면 때문에 기준이 달라질 수 있습니다. 기기에 보존할 콘텐츠가 없는지 확인하지 않은 채 전체 적용으로 덮어쓰지 마세요. 기록 도중 실패했다면 원본 업데이터로 전체 복구가 필요할 수 있습니다.

## 6. 자동 시작·최소화·종료

- 상단 **Windows 시작 시 자동 실행**을 체크하면 현재 사용자 계정에 등록되고, 로그인 시 트레이에서 시작합니다. 체크를 해제하면 등록을 제거합니다.
- **최소화:** 트레이로 이동하고 연결은 유지합니다.
- **X 버튼:** 트레이로 이동 / 완전 종료 / 취소 중에서 선택합니다.
- **트레이 아이콘:** 기본 동작 또는 메뉴의 **열기**로 편집기를 다시 엽니다. 메뉴의 **완전 종료**로 종료할 수도 있습니다.
- 프로그램을 다시 실행해도 중복 실행하지 않고 기존 창을 엽니다. 다른 버전의 연결 프로그램은 별도로 종료해야 합니다.
- 설정과 사용자 아이콘은 실행 폴더의 `data/`에 저장됩니다. 새 버전으로 옮길 때 기존 프로그램을 종료하고 폴더를 보관하세요. `data/`에는 개인 경로가 있으므로 GitHub에 올리지 마세요.

## 7. 자주 발생하는 상황

| 상황 | 확인할 내용 |
|---|---|
| 아이콘을 눌러도 앱이 안 열림 | PC 프로그램 연결 켜짐, NumLock, 실행 대상 경로를 확인하고 홈으로 나갔다가 스트림덱에 다시 진입합니다. |
| 타이핑에 `-`/`+`가 입력되지 않음 | 연결 중에는 예약되는 키입니다. 일반 입력이 필요하면 연결 끄기를 누릅니다. |
| 스트림덱에서 숫자를 누르면 앱이 열림 | 이 모드에서는 물리 넘패드도 바로가기로 사용합니다. 뒤로가기로 해제합니다. |
| 업데이터의 Start가 보이지 않거나 눌리지 않음 | USB 모드와 화면 꺼짐을 확인하고 재연결을 잠시 기다립니다. 다른 업데이터·화면 통신 도구가 포트를 잡고 있지 않은지도 확인합니다. |
| 경로를 저장했는데 키보드 이름·아이콘이 그대로임 | 설정 저장은 PC 실행 대상만 반영합니다. 화면 변경에는 아이콘 적용이 필요합니다. |
| 적용 후 연결은 켜졌는데 버튼이 안 먹음 | 키보드를 재시작한 뒤 홈 → 스트림덱으로 다시 진입합니다. |
| CRC 불일치·전송 오류 | 오류를 확인하고 반복 기록하지 마세요. 기준 불일치는 기록 전에 중단하며, 기록 중 오류는 전체 복구가 필요할 수 있습니다. |
| CPU·GPU·날씨·습도 값이 갱신되지 않음 | 이 배포에는 실시간 정보 도우미가 포함되지 않습니다. 스트림덱 연결 기능과 별개입니다. |

개발·시험은 USB 모드의 L99 한 대(표시 버전 V1.29)에서 진행했습니다. 다른 개정판·무선 모드의 호환성은 확인하지 않았습니다. 배포용 기본 설정 화면 자체를 새로 기록하는 실기기 재시험은 하지 않았습니다.
